# Compute Resources

We provide the basic concepts of CPU and GPU resources that are useful for understanding distributed systems and Ray.

---

## CPU

**Physical CPU, Core, and Logical CPU**

* A physical CPU refers to a CPU socket or processor package.
* Each physical CPU contains multiple physical cores.
* If Simultaneous Multithreading (SMT) is enabled, each physical core can expose multiple hardware threads to the operating system (OS).
* Each hardware thread is typically exposed as a logical CPU.

If there are `N` physical CPUs, `M` physical cores per CPU, and `K` hardware threads per core, then 

```text
Logical CPUs = N × M × K
```

**Multiprocessing**

Multiprocessing means running multiple processes to perform work.

* Each process has its own separate (virtual) memory address space.
* Different processes can run on different logical CPUs.
* Multiprocessing is commonly used for CPU-bound workloads in standard CPython because each process has its own Python interpreter and its own Global Interpreter Lock (GIL).

```text
Process A
Process B
Process C
Process D
```

#### Multithreading

Multithreading means running multiple threads within a single process.

* Threads within the same process share the same memory space.
* The operating system schedules software threads onto available logical CPUs.

```text
Process A
├── Thread 1
├── Thread 2
└── Thread 3
```

#### Hardware Thread vs Software Thread

The term thread in SMT and the term thread in software programming are related but refer to different concepts.

* An SMT hardware thread is a hardware execution context exposed by the CPU.
* It is typically visible to the OS as a logical CPU.
* A software thread is an execution unit created by a process and scheduled by the operating system.

---

## GPU

* A GPU is a compute device designed to execute a large number of operations in parallel.
* GPUs have their own memory, commonly called VRAM.
* GPU workloads can use many execution units concurrently.
* A single process may use one or more GPUs, and multiple processes may also share or compete for the same GPU depending on configuration.
